# Selenium IDE – Website Automation Testing

## 📌 Project Overview

This project demonstrates **functional automation testing** using Selenium IDE on the practice website [The Internet – Herokuapp](https://the-internet.herokuapp.com/).

The project automates various website functionalities, including login, form inputs, checkboxes, dropdowns, JavaScript alerts, dynamic elements, file uploads, and browser interactions.

The tests are created using Selenium IDE's record-and-playback functionality, making the project beginner-friendly and requiring minimal programming.

---

## 🎯 Project Objectives

- Understand the fundamentals of software testing and automation testing.
- Learn how to create and execute automated test cases using Selenium IDE.
- Test different functionalities of a web application.
- Verify expected results using assertions.
- Identify functional issues through automated test execution.
- Understand test execution, test results, and test documentation.

## ▶️ How to Run the Project

1. Install Mozilla Firefox.
2. Install the Selenium IDE extension.
3. Open Selenium IDE.
4. Open the saved `.side` project file.
5. Select the desired test case.
6. Click the Play button to execute the test.
7. Observe the execution results.
8. Review successful and failed commands.

## 📊 Test Execution Results

Test cases are executed using Selenium IDE.

The results are evaluated based on whether the application behaves according to the expected outcome.

| Status | Description |
|---|---|
| PASS | The test meets the expected result |
| FAIL | The test does not meet the expected result |
| NOT EXECUTED | The test has not yet been executed |

*Actual execution results and screenshots will be added after test execution.*
